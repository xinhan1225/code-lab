# 实验室升级计划

日期：2026-10-26

## 用户目标

关卡更多且难度缓慢提升；任务面板突出；整页成为实验室，允许通过 JavaScript 改变真实页面，下一关重置；机器人通关庆祝。

## 决定与范围

- 机器人路线扩充为 18 关，JS/Rust 共用，按入门动作→转向→简单循环→变量→条件→综合分段。原六关 ID 保留，新关插入课程顺序，避免旧成绩和草稿被赋给其他内容。
- 新增 6 个 JavaScript 网页实验：文字、文字颜色、墙面配色、CSS 主题变量、类名控制灯光、综合布置。操作真实页面中的指定元素，不另做假的预览；支持明确的 DOM API 子集，不执行任意代码。
- 网页实验、机器人实验独立保存进度与草稿；切关/切路线/重置清除页面改造与庆祝状态，草稿保留。
- 任务卡用亮色边界、编号、具体目标清单和课程难度说明；网页实验显示可点击复制的目标元素与示例。
- 全页采用实验室墙面、指示灯、舱室标牌的氛围，原工作台继续作为编程控制台。
- 机器人庆祝：一次通关触发跳跃、双臂动作、扩散光环与彩屑；切关清理；尊重减少动态效果设置。

## 模块分工

- curriculum 子代理：18 关数据及全部双语解法/顺序检查。
- page_lab 子代理：6 个网页实验、受限 DOM 指令解析/应用/重置/条件验证及测试。
- 主模型：任务视觉、全页实验室、路线切换、执行调度、保存与迁移、机器人特效、浏览器验证、更新现有私有站点。
- 独立审查：输入约束、状态清理、成绩兼容、教学正确性。

## 验收

- 36 个机器人双语解法和 6 个网页实验均能通关；每个新概念有过渡练习。
- 页面实验修改真实 DOM，执行行与目标验证一致；恶意或不支持的代码给出明确错误。
- 切换实验立即恢复基准页面；旧进度与草稿正确保留，不发生 ID 混淆。
- 任务一眼可见，当前目标与完成状态清晰；手机无横向溢出。
- 通关庆祝实际出现，下一关/重置后消失；无重复启动或永续动画泄漏。
- 更新同一个线上站点和可下载交付包。
