## 支持边界

- 使用受限教学解释器，支持本课程所需语法，非完整 Rust 编译器或任意 JavaScript 执行环境。
- 静态检查所有分支并预展开循环，未执行代码中的错误也可能提前报告；这一点与完整语言运行时不同。
- 未验证 Safari、Firefox、真实手机硬件或辅助阅读器；已检查 Edge 桌面及模拟窄屏、键盘访问和语义标签。
- 本地离线使用需 Node.js；已包含 Wasm，无需玩家安装 Rust。
- 本地进度属于当前浏览器和站点地址；本地与在线入口不会共享进度。
