# 双语代码实验室：任务计划书

日期：2026-10-26

## 项目目标

交付可直接游玩的中文网页编程游戏，用修复实验室机器人的剧情帮助大学生理解 JavaScript 与 Rust 的变量、函数、循环及条件判断。适合课堂现场演示，也能独立练习。

## 已确定的方案

采用代码编辑与机器人迷宫并排的单屏工作台。玩家阅读目标、修改短代码、运行、观察逐步运动及错误反馈，完成后解锁下一关。两种语言共用地图与目标，各自拥有真实语法的起始代码、提示、参考答案和知识解释。

比较过三种方案：纯知识问答易实现但反馈较弱；完整在线编译器能执行任意代码但增加服务器与隔离环境；本项目选择支持明确教学语法的浏览器解释器，配合 Rust 游戏规则模块，兼顾可玩性和交付可靠性。编辑器明确说明支持范围，不伪装成完整编译器。

## 交付范围

- 6 个循序渐进的机器人关卡，每关提供 JavaScript / Rust 两种模式，共 12 次学习挑战。
- 可编辑代码、运行/停止、单步、重置、渐进提示、参考答案、语法反馈。
- 机器人移动、朝向、墙体碰撞、电池收集、终点判定和逐条执行日志。
- 通关进度本地保存，按语言分别记录；切换关卡与语言不会串用成绩。
- 完成反馈、下一关、课程说明、声音开关、键盘操作及窄屏布局。
- Rust 源码与实际编译的 WebAssembly 规则模块（环境可用时）；工具不可用时明确记录替代方式与边界。
- 计划书、内置生图产生的界面设计图、可玩源码、启动方式与交付说明。

## 视觉方向

深色实验室操作台，青绿色主色、柔和琥珀色点缀。左侧课程导航，中间编辑器和任务说明，右侧大幅等距机器人迷宫。清晰中文文字、适度像素风图形、精细边框与低强度荧光。以生成的界面图为版式和颜色依据，用真实可操作的 HTML/CSS/Canvas 重现。

## 实施顺序

1. 完成本计划及文件边界，核查环境。
2. 用内置生图生成主界面，保存原图与提示词，观察后锁定视觉方案。
3. 实现关卡、受限教学解释器及 Rust 规则模块。
4. 按设计图实现界面、地图渲染、状态与交互，整合核心模块。
5. 验证全部关卡的双语参考答案、错误代码、碰撞、停止/重置、语言切换与进度恢复。
6. 浏览器实际游玩、检查布局，交付并打开可玩游戏。

## 文件与分工

- 主模型：计划、生成图片、界面、整合、运行验证与交付。
- 核心模块子代理：`dist/core.mjs`、`dist/levels.mjs`、Rust 源码、核心测试；接口在生成图片后确定。
- 独立审查：检查教学语法、关卡可解性、状态切换与最终可玩性，不代替实际运行。
- `dist/index.html`、`dist/styles.css`、`dist/app.mjs`：可玩的静态网站。
- `design/`：生成界面图与提示词。
- `scripts/`：本地启动与必要构建工具。
- `README.md`：启动、操作、汇报内容及支持边界。

## 验收条件

- 打开游戏能开始第一关，所有可见控件有实际作用。
- 6 关的双语参考答案均能通关；错误代码给出中文反馈；无限循环或超量指令不会卡住网页。
- 运行中切换语言/关卡、重置或停止，不残留旧执行状态。
- 刷新恢复进度，存储被禁用或内容损坏时仍能游玩。
- JS 与 Rust 语法具有有意义差异，Rust 在项目中有清晰、诚实的技术角色。
- 桌面与手机宽度都能阅读与操作；键盘可访问主要按钮。

## 项目边界

不加入账号、排行榜、多人联机或任意代码云端编译。教学解释器只支持所列关卡需要的语法；它用于练习，不替代 JavaScript / Rust 的完整运行环境。
