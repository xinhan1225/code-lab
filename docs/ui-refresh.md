# UI 改版 · 2026-10-26

## 设计方向

将视觉顺序收敛为「读懂目标 → 编写代码 → 运行并观察」。默认界面使用米白、炭灰和低饱和森林绿，降低导航与状态信息的视觉权重。运行按钮是主要操作，提示和重置采用文字按钮；知识点和导师说明使用原生 details 按需展开。

移除默认环境网格、渐变、光晕、地图取景角标和叠套卡片。棋盘采用浅色实体模型配色，仍由原 Canvas 绘制和交互。网页课程触发的星空、蓝图、派对等效果保留，深色背景下文字自动适配。主题变量继续改变按钮、导航、进度与环境灯；按钮背景充分压暗以保持白字对比，标题染色保留实际指定颜色并提供深色底衬。
